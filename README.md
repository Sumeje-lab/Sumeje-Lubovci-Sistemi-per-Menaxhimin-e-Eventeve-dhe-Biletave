# Sistemi për Menaxhimin e Eventeve dhe Biletave

Aplikacion web për krijimin e eventeve dhe menaxhimin e rezervimeve të biletave.

## Teknologjitë
- PHP
- MySQL
- XAMPP
- HTML

## Databaza
Emri: `event_managment`

## Funksionalitetet
- Shfaqja dhe krijimi i eventeve
- Rezervimi i biletave
- Llogaritja e çmimit total
- Shfaqja dhe anulimi i rezervimeve
- Përditësimi i biletave të disponueshme

## Ekzekutimi
1. Aktivizo Apache dhe MySQL në XAMPP.
2. Sigurohu që databaza `event_managment` është krijuar.
3. Hap `http://localhost/event_managment/` në shfletues.

## Zhvillimet e ardhshme
- Regjistrimi dhe kyçja e përdoruesve
- Përmirësimi i ndërfaqes grafike
